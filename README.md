# coding-interview-solutions
Coding interview solutions in Java &amp; Kotlin with clean design, tests, and explanations.

This repository contains my personal collection of **coding interview solutions** implemented in **Java and Kotlin**.

The focus is not only on solving problems, but on writing **clean, readable, and maintainable code**, similar to what I would deliver in a production backend system.

---

## 🎯 Goals of this repository

- Practice and reinforce **core computer science concepts**
- Prepare for **technical interviews** (coding & system design)
- Demonstrate **clean coding, OOP, and design principles**
- Serve as a **quick revision resource** before interviews

---

## 🛠️ Technologies & Concepts

- Java (collections, generics, streams)
- Kotlin (idiomatic usage where relevant)
- Data Structures (Stack, Queue, Map, Tree, Graph)
- Algorithms (search, sorting, recursion, dynamic programming)
- OOP & SOLID principles
- Design patterns (Strategy, Factory, etc.)
- Unit testing (JUnit)
- Reflection & annotations (where applicable)
